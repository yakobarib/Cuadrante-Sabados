Guardado automático (recomendado)

Configura una sola vez un token de GitHub para que "Guardar cambios" escriba directamente en el repositorio, sin copiar/pegar nada.

  1. Abre crear token de GitHub.
  2. En "Repository access" elige Only select repositories → Cuadrante-Sabados.
  3. En "Permissions" → "Repository permissions" → Contents → Read and write.
  4. Genera el token y pégalo aquí (solo se guarda en este navegador, en ningún otro sitio):
