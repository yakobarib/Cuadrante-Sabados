📅 Cuadrante Sábados

Marca quién falta y la web calcula sola quién cubre Teléfonos y Mostrador.

❓ Ayuda

Mes: elige el mes que quieres ver o editar. Los meses ya guardados se cargan solos; "+ Nuevo mes" crea uno vacío.

👥 Personal (junto a "+ Nuevo mes"): añade o quita gente de Teléfonos/Mostrador de cada grupo, reordena con las flechas ↑/↓ quién refuerza primero a Teléfonos si hace falta, y renombra a alguien pulsando el ✏️ junto a su nombre. Tiene su propio botón de guardar.

🖨️ Imprimir mes: genera una hoja lista para imprimir o guardar como PDF con el resumen del mes.

En cada tarjeta de sábado: pulsa "Festivo" si ese día no se trabaja, elige el Grupo que le toca, y pulsa el nombre de cada persona para marcarla ausente o disponible (se ve al momento quién queda cubriendo Teléfonos/Mostrador). El desplegable "Detalles" muestra quién cubre cada rol tras aplicar los refuerzos; si hay algún problema, aparece siempre visible debajo, aunque "Detalles" esté cerrado.

+ Sustitución Manual: úsalo cuando alguien de fuera del grupo del día viene a cubrir a otra persona (cambios de sábado, favores). Marca la ausencia sola y hace que el sustituto cuente para los mínimos.

💾 Guardar cambios (arriba a la derecha): en gris si no hay nada nuevo, en azul y parpadeando si tienes cambios sin guardar. Guarda el mes y, si hay alguna incidencia, te avisa por email.

⚙️ Ajustes: configura el guardado automático (un token de GitHub, una sola vez), o usa el copiar/pegar manual si no quieres configurarlo.

⚙️ Ajustes

Hay dos formas de guardar los cambios en GitHub. Elige la que te resulte más cómoda — puedes cambiar de una a otra cuando quieras.

Opción A · Sin configurar nada

No requiere entender nada de GitHub. Cuatro pasos, cada vez que guardes:

  1. Pulsa "Copiar JSON del mes" aquí abajo.
  2. Pulsa el enlace "Abrir en GitHub" (se abre en una pestaña nueva).
  3. Dentro, haz clic en el recuadro de texto, selecciona todo (Ctrl+A) y pega (Ctrl+V).
  4. Baja del todo y pulsa el botón verde "Commit changes".
Abrir en GitHub →

Opción B · Guardado con un clic

Configuras esto una sola vez y, a partir de ahí, "Guardar cambios" escribe directo en GitHub sin copiar ni pegar nada. Tarda un par de minutos:

  1. Abre este enlace de GitHub (te pedirá iniciar sesión si no lo has hecho).
  2. En "Repository access" marca "Only select repositories" y elige Cuadrante-Sabados en el desplegable que aparece.
  3. Baja hasta "Permissions" → "Repository permissions", busca la fila "Contents" y cambia su valor a "Read and write". No toques nada más.
  4. Baja del todo y pulsa el botón verde "Generate token".
  5. Copia el código que empieza por github_pat_... (solo se muestra una vez) y pégalo aquí:

Se guarda solo en este navegador — nunca se envía a ningún otro sitio.
