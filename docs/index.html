📅 Cuadrante Sábados

Marca quién falta y la web calcula sola quién cubre Teléfonos y Mostrador.

❓ Ayuda

Mes: elige el mes que quieres ver o editar. Los meses ya guardados se cargan solos; "+ Nuevo mes" crea uno vacío.

En cada tarjeta de sábado: pulsa "Festivo" si ese día no se trabaja, elige el Grupo que le toca, y pulsa el nombre de cada persona para marcarla ausente o disponible (se ve al momento quién queda cubriendo Teléfonos/Mostrador, y si hay algún problema).

+ Sustitución Manual: úsalo cuando alguien de fuera del grupo del día viene a cubrir a otra persona (cambios de sábado, favores). Marca la ausencia sola y hace que el sustituto cuente para los mínimos.

💾 Guardar cambios: guarda el mes. Si hay alguna incidencia (faltan personas para llegar al mínimo), te avisa por email.

👥 Personal: añade o quita gente de Teléfonos/Mostrador de cada grupo, y reordena con las flechas quién refuerza primero a Teléfonos si hace falta. Tiene su propio botón de guardar.

⚙️ Ajustes: configura el guardado automático (un token de GitHub, una sola vez), o usa el copiar/pegar manual si no quieres configurarlo.

🖨️ Imprimir mes: genera una hoja lista para imprimir o guardar como PDF con el resumen del mes.

Guardado automático (recomendado)

Configura una sola vez un token de GitHub para que "Guardar cambios" escriba directamente en el repositorio, sin copiar/pegar nada.

  1. Abre crear token de GitHub.
  2. En "Repository access" elige Only select repositories → Cuadrante-Sabados.
  3. En "Permissions" → "Repository permissions" → Contents → Read and write.
